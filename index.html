How a pod is marked SPM ready

  1. Reads every root pod and exact version from the PODS section.
  2. Finds the published podspec on the CocoaPods CDN (sharded by MD5 of the pod name) and takes its source.git. Binary podspecs that point source.http at a GitHub release or archive have their repository inferred from that URL.
  3. Probes the repository for Package.swift at the podspec tag, the version tag, and common v/name-prefixed spellings. GitHub, GitLab, Bitbucket, Gitee, and Codeberg/Gitea hosts are supported.
  4. When the package lives in a separate repo, tries common names such as Project-spm and swift-package-manager-Project. Use the overrides box for anything else.

Only the main CocoaPods trunk is checked. Private pods, custom spec repos, self-hosted git hosts, and binary pods without an inferable GitHub repository are reported as unresolved.
